MODEL INTERPRETATION

Feature importance

The saved evaluation file does not include feature-importance measurements. The Overview page shows observed group averages only; those comparisons do not establish cause or feature influence.

LIVE PREDICTION

What the form uses

The current Node.js /predict endpoint calculates backlog and placement estimates using a fixed scoring formula. The Random Forest figures above describe saved offline model evaluation and are not the model currently called by the form.

Evaluation file: model_evaluation.json. Dataset: Student_Backlog_Placement_Dataset_No_Subject_Attendance.csv. Scores are estimates and do not guarantee individual employment outcomes.

Placement Compass uses your academic and professional signals for an indicative assessment.
